# 场景搭建模块

新建「场景搭建」项目后，右侧显示结构树、3D 画布和下半部属性区。可以导入 STEP 装配或单机器人 URDF，从 CAD 零件搭建 Link/Joint，编辑父子关系、关节原点、轴和限位，预览关节运动、撤销编辑，并导出 URDF 与配套 STL。

## 导入与导出

- [STEP 解析器](../../modules/scene/README.md)由 C++ 和 OCCT 构建，随桌面应用分发。后端按需启动解析进程，读取 JSON 装配和 STL 网格。原始装配使用固定连接记录 CAD 层级，不作为构建场景的关节关系。个别曲面网格化失败时，导入结果记录受影响的零件和跳过的曲面数量。零件没有可用三角面时，导入失败并保留当前场景。
- 导入 STEP 时保留原始 CAD，并将构建场景初始化为空的 base_link；构建画布不显示未分配的原始几何。在原始模型中单选或多选零件/装配，可分配到已有 Link 或创建新 Link/Joint；选择装配自动展开到有几何的后代。同一零件只能归属一个 Link，重新分配或解除绑定需确认。两个视图共用这份可编辑配置，不改写源 CAD。普通导入替换当前场景；补录原始 STEP 保留已有编辑，但存在零件绑定时禁止替换，以免引用失效。
- URDF 1.0 导入支持盒、球、圆柱、同目录树中的 STL、多个 visual，以及固定、旋转、连续旋转和移动关节。导出时在所选目录内创建独立文件夹，URDF 引用预览使用的同一份 STL。导入说明通过 URDF 注释保留。关节的当前预览位置存于场景文档，URDF 保存关节原点和限位。

## 数据与并发

- `projects/<projectId>/scene/document.json` 和 `meshes/` 位于应用数据目录。`sourceRobot` 保留 CAD；`robot.links[].sourceParts` 保存零件 ID 和 Link 零位坐标系中的固定偏移，原有 `visuals` 保留手工/导入 URDF 几何。渲染与导出共用几何解析，复合零件偏移和 visual 原点；创建 Link 时取首个几何零件坐标，按父级逆变换保留装配零位，后续关节编辑带动绑定几何运动。删除 Link 或解除绑定不删除源数据。文档的可选 `transparencies` 按源零件或原生 URDF Link 保存显示透明度，默认 0%；旧的全局 `transparency` 不属于当前文档格式，会被校验拒绝。源装配/构建连杆的选择展开到子级，绑定几何共用源零件设置，单个 Link 内可包含不同透明度的零件；混合选择显示“混合”。显示透明度不修改 CAD 或导出的 URDF 材质。聊天附件保存在该目录下的 `attachments/`；Pi 原生消息保存附件引用。不读取或迁移旧版场景，需要重新导入源模型；磁盘旧文件不会被主动删除。
- 界面和 Pi 共用 `src/backend/module/scene/service.ts`。修改进入项目级队列，校验版本后原子写入文档并广播 `scene.document`。STEP 解析在队列外执行，提交前再校验版本。导入失败、被取消或遇到版本冲突时，当前场景保留。进程内保存最近 20 次可撤销修改。
- 画布和结构树同步选中。关节拖动在本地预览，松手后以拖动开始时的版本提交。属性显示相对父级和世界坐标，画布提供 20 × 20 米的 XY 网格、每格 1 米，以及世界原点和 XYZ 轴。

## Pi 工具

| 工具 | 行为 |
| --- | --- |
| `scene_get` | 读取场景版本、运动关系、位置和限位 |
| `scene_import_step` | 导入聊天中选择或拖入的 STEP 附件，保存原始模型并将场景重置为 base_link |
| `scene_set_joint_position` | 按版本调整关节位置，在请求批准模式沿用应用的确认交互 |

接口定义见 `src/contracts/scene.ts`。回归覆盖 STEP 导入、多选归组与旋转坐标换算、重新分配/解除绑定、关节配置校验、双视图编辑、保存/重启、撤销、独立 URDF/网格导出及并发版本冲突，入口为 `tests/backend/scene/`、`tests/renderer/scene/` 及桌面集成测试。Pi 工具暂不提供零件分配和关节结构编辑，这些操作在属性区完成。
