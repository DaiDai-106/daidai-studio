# 场景搭建模块

新建「场景搭建」项目后，右侧显示结构树、3D 画布和属性。可以导入 STEP 装配或单机器人 URDF，重命名、增删子连杆、预览和调整关节位置、撤销编辑，并导出 URDF 与配套 STL。

## 导入与导出

- [STEP 解析器](../../modules/scene/README.md)由 C++ 和 OCCT 构建，随桌面应用分发。后端按需启动解析进程，读取 JSON 装配和 STL 网格。CAD 装配按固定关节导入。个别曲面网格化失败时，导入会列出跳过的曲面。零件没有可用三角面时，导入失败并保留当前场景。
- 导入 STEP 时，同时保存只读原始装配和可编辑场景。「原始模型」可补录原始 STEP，已有编辑会保留。
- URDF 1.0 导入支持盒、球、圆柱、同目录树中的 STL、多个 visual，以及固定、旋转、连续旋转和移动关节。导出时在所选目录内创建独立文件夹，URDF 引用预览使用的同一份 STL。导入说明通过 URDF 注释保留。关节的当前预览位置存于场景文档，URDF 保存关节原点和限位。

## 数据与并发

- `projects/<projectId>/scene/document.json` 和 `meshes/` 位于应用数据目录。文档记录版本和网格 ID。聊天附件保存在该目录下的 `attachments/`；Pi 原生消息保存附件引用。旧版场景留在原位置，可重新导入模型。
- 界面和 Pi 共用 `src/backend/scene/service.ts`。修改进入项目级队列，校验版本后原子写入文档并广播 `scene.document`。STEP 解析在队列外执行，提交前再校验版本。导入失败、被取消或遇到版本冲突时，当前场景保留。进程内保存最近 20 次可撤销修改。
- 画布和结构树同步选中。关节拖动在本地预览，松手后以拖动开始时的版本提交。属性显示相对父级和世界坐标，画布提供 20 × 20 米的 XY 网格、每格 1 米，以及世界原点和 XYZ 轴。

## Pi 工具

| 工具 | 行为 |
| --- | --- |
| `scene_get` | 读取场景版本、运动关系、位置和限位 |
| `scene_import_step` | 导入聊天中选择或拖入的 STEP 附件，成功后替换场景 |
| `scene_set_joint_position` | 按版本调整关节位置，在请求批准模式沿用应用的确认交互 |

接口定义见 `src/contracts/scene.ts`。回归覆盖 STEP 导入、URDF 往返、坐标变换、关节拖动和并发版本冲突，入口为 `tests/backend/scene/`、`tests/renderer/scene/` 及桌面集成测试。

后续可在现有文档模型上增加连杆归组、坐标编辑和关节参数定义。
