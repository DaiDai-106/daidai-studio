# 前端与交互

本文描述当前实现。未实现的布局目标和能力列在末节；文件、Git 和网页预览的具体边界见 [Coding 工作区](coding_workspace.md)，业务持久化见 [后端与数据](backend.md)。

## 项目入口与布局

启动显示项目主页，提供新建项目、打开已知项目和设置；不预加载场景或启动全部 worker。新建项目选择名称、Coding / 场景 / 机器人模式及可选工作目录；未选目录时在系统 Documents/Dai 下创建，同名目录自动加数字后缀。项目以 ID 隔离，多个项目可以指向同一目录。

左侧项目栏直接列出各项目的会话，支持新建、重命名、分叉、归档和删除；项目可移除并从已隐藏列表恢复。移除项目不删除工作目录、聊天或场景。主页、工作台和设置都提供返回入口；没有活动聊天时，项目功能区仍可使用。

| 项目模式 | 当前宽窗口布局 | 布局恢复 |
| --- | --- | --- |
| Coding | 左侧项目栏、中间 AI 对话、右侧可收起的文件 / diff / 网页工作区 | 展开状态、比例、导航和最多 100 个文件 / diff 标签按项目保存 |
| 场景搭建 | 左侧项目栏、中间三维场景、右侧 AI 对话 | 场景业务数据持久化；面板宽度、视角和选中项不跨重启恢复 |
| Dai Robotics | 左侧项目栏、中间演示设备、右侧 AI 对话 | 演示选择和面板宽度仅保留在当前应用运行期间 |

Coding 首次默认收起，后续恢复已保存的展开状态；展开时默认与聊天平分项目栏以外的可用宽度；文件 / 变更导航位于内容右侧，可独立收起。各模式可拖动分隔条；窄窗口通过聊天 / 功能区页签切换。项目栏可收起，设置返回保留工作上下文；Coding 收起后聊天采用居中限宽，展开按钮位于聊天标题栏。文件工具栏复用共享图标按钮与主题变量，操作在右侧成组排列。原生网页预览不能遮挡设置、菜单或弹窗。

## 组件与状态归属

| 代码 | 职责 |
| --- | --- |
| `app/components/app.tsx` | 组合项目导航、主页、设置及全局弹窗 |
| `app/components/project_workspace.tsx` | 组合各模式面板、聊天、分隔条、STEP 导入及扩展询问；拥有临时布局状态 |
| `app/logic/application_client.ts` | 工作区快照、写入队列、局部事件、聊天流及其版本规则 |
| `app/logic/use_application.ts` | 将客户端状态接入 React 订阅 |
| `app/logic/use_workbench_navigation.ts` | 项目 / 会话切换、草稿提交及统一激活 / 清空入口 |
| `features/chat/logic/use_conversation_drafts.ts` | 会话草稿缓存及退出前保存 |
| `features/coding/logic/use_coding_workspace.ts` | 项目级内容标签、导航、比例、展开状态及恢复提示 |

业务数据归项目或会话，临时布局归界面。场景和项目工作区属于项目，不依赖当前聊天；聊天历史由 Pi SessionManager 保存，界面投影不另存为第二份历史。跨进程类型复用 `src/contracts/`，小功能平铺，较大功能再分组件、逻辑和样式。

## 数据流与状态

界面经 `window.desktop.application` 读取工作区和会话并订阅事件；`application_client.ts` 将快照、分页和事件合并为 `{ workspace, view, error }`，React 通过 `use_application.ts` 订阅。`workspace` 包含项目、会话元数据、设置和待处理交互；`view` 包含当前会话历史、流式内容、工具状态和错误，具体字段以 `src/contracts/application.ts` 为准。

项目/会话选择与草稿由导航和草稿 hook 协调；临时弹窗、面板与窄屏切换由界面持有。Coding 布局单独按项目保存在本地，场景内容由后端保存；网页实例、场景视角和机器人演示选择不是跨重启的业务数据。状态及事件一致性规则见 [后端](backend.md#聊天推送与历史投影)和 [Coding 工作区](coding_workspace.md#状态与数据结构)。

## 切换、保存与失败

导航和正常退出前保存聊天草稿；失败有反馈，不声称未完成的数据已保存。运行中允许回项目主页，任务继续；可返回运行中的会话查看或停止，切换其他会话 / 项目及破坏性操作仍受限制。同项目切换聊天保留文件标签和共享场景，跨项目响应按身份和版本隔离。

客户端按提交顺序处理会话修改。快照、分页的成功与失败都检查请求版本、数据版本及连接代次；过期分页不追加记录、不修改游标、不报到当前界面。重复分页共用请求，当前失败允许重试。删除记录防止迟到快照复活会话；当前会话切换失败会恢复原视图，旧切换的失败不污染新选择。

Coding 标签与布局的保存、恢复及限制见 [Coding 工作区](coding_workspace.md#状态与数据结构)；本机界面状态不构成项目备份。

## AI 对话与场景

支持流式回复、公开思考摘要、Markdown、图片、模型与推理档选择、工具过程、授权询问和停止。原生压缩/分支摘要与可见扩展消息以可展开记录展示；输入区下仅保留累计 tokens 与估算费用，点击查看缓存、上下文及分支明细；Coding 不显示额外说明行。侧栏仅高亮当前会话（项目主页时高亮项目），回复中以转圈图标替代会话图标。用量区分会话累计与当前分支，口径见 [后端说明](backend.md#用量原生记录与项目指令)。新会话独立，从已有会话分叉继承历史；标题默认按首条消息生成，手动名称保留。

后端缓存已提交历史，并合并高频进度帧；前端复用历史数组、缓存轮次分组，只更新当前流式轮次。未变化的已完成轮次和其中的文件链接不随每个片段重新计算。历史提交后再更新分组；停止或最终失败不能被旧进度覆盖。协议与缓存规则见 [后端与数据](backend.md)。

Coding 的 `@` 文件引用使用紧凑候选列表和文件标签，无行范围表单；发送时读取真实文件并保留内容快照；界面不暗示模型可以看到未提供的文件或网页。场景工具读取当前项目已提交状态；前端对象引用草稿入口已移除。后端 `conversation.send` 契约仍接受场景对象引用，并校验项目、对象和场景版本。

场景支持系统选择器 / 拖拽导入 STEP，已有场景时明确选择添加或替换；失败或取消不替换已有提交。支持对象选择、删除、变换、关节草稿确认 / 移除及源文件重新定位。源文件移动或变化须校验，不能把其他项目的旧模型显示为当前场景。共享场景、单位和提交语义见 [场景 Runtime](scene_runtime.md)。

## 设置与当前范围之外

设置管理外观、快捷键、模型与认证、Pi package、Skill、运行环境和应用信息。MCP 仅由 Pi package 提供，Skill 支持新建、编辑及完整目录导入，包内 Skill 默认只读，见 [Package 与 Skill](packages.md)。

统一将场景和机器人功能区移至右侧仍是布局目标，尚未实施。Coding 编辑器、终端、运行、可移植项目文件、撤销系统、真实机器人接入和 URDF 导出均未实现，不作为当前界面承诺。新版本不读取或转换旧 `general` 项目，原数据保留。
