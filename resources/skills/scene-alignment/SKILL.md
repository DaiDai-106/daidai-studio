# 场景对齐

根据实际观察确定设备上下方向；证据不足时询问，不猜测或反复试转。六视角图标记的是当前世界方向，按图判断时使用 `world_axis`，由插件换算模型坐标。仅确定上下时使用 `alignment_align_direction`；上下与前方都明确时使用 `alignment_align_frame`。已给出旋转轴和角度时直接使用 `alignment_rotate`。

用户要求先预览，且变换的方向、枢轴等参数已经明确时，对相应定位工具设置 `preview: true` 并传入最新 revision，返回的是计算前后数据，不会改变保存的定位或画面。明确说明只是预览；用户要求应用时再次核对当前 revision 后调用相同操作并省略 preview。若参数存在歧义，先询问，不把猜测作为已确认的预览。用户已明确要求直接操作时无需强制预览。

用户明确要求撤销上一次定位时，调用 `scene_undo_placement`，传入当前 importId 和最新 revision。它将前一姿态作为新版本提交；再次撤销会撤销上次撤销，在两个姿态间切换，不是连续回溯多步历史。不要自行计算反向旋转或重放旧操作。版本冲突时读取当前场景并说明，不自动覆盖。

用户要求落地时，用 `scene_inspect` 的 `order=lowest` 查询低处物体及其世界边界，再用 `scene_get_features` 批量读取已确认地脚的水平接触面，将精确 `objectId` 和 `featureId` 交给 `alignment_ground`。地面高度未指定时使用世界 Z=0。该工具仅移动世界 Z；比较返回的各接触高度，不一致时如实报告，不能声称所有地脚落地。归零、旋转和落地是不同操作。

需要在整个场景查找线索时，可用 `scene_find_features` 分页筛选世界空间的平面或圆柱方向与特征原点高度。它只提供几何候选，不证明候选是吊环或地脚；原点高度不代表整个面的最低点。若 `featureCacheComplete` 或 `displayComplete` 为 false，明确说明数据不完整，结合其他证据判断，必要时询问用户。

使用当前 importId 和最新 revision；每次修改完成后再进行下一步，版本冲突时先读取当前状态，不盲目重放旋转。无需 Bash 计算坐标，不改变零件间相对位置。完成后查看结果并说明实际完成的操作。
