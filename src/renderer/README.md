# 前端目录说明

此目录是 Electron 的渲染界面。前端通过桌面桥接访问应用能力，前后端共用的数据契约位于 `src/contracts/`。

- `app/`：应用布局、应用级状态、桌面窗口与工作台协调。
- `shared/`：前端多处共用的界面组件、类型、工具和样式。
- `features/`：聊天、项目、场景、机器人和设置等功能。
- `styles/`：主题变量、基础元素样式以及全局样式加载入口。

功能目录内，`components/` 放 React 组件（TSX），`logic/` 放状态、类型与工具（TS），`styles/` 放 CSS。`main.tsx`、`index.html` 和环境声明是构建入口，保留在根目录。

全局样式在 `styles/index.css` 中按既有顺序加载；仅由特定组件使用的样式由该组件引入。增加或调整样式时应检查浅色、深色和窄窗口，避免全局规则影响其他功能。

遵循仓库的 Biome 格式。中文注释说明职责、约束和不直观的原因，不逐行重复代码。涉及跨进程数据时使用 `src/contracts/` 的契约，避免在前端复制一套定义。
